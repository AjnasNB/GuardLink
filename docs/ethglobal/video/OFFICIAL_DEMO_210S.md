Keep a quiet persistent chapter rail: Join / File / Review / Follow / Govern. Small persistent disclosure on test footage: “Testnet · Synthetic evidence · Demo identities”.

Use two distinct fixtures. CASE A is the main approval/payout demonstration. CASE B is a separate rejection/appeal excerpt, explicitly labelled when it begins. Preserve each actual UI case ID and its canonical onchain mapping. Never splice their histories into one case. All nine actor accounts are demo identities, not insured members or real jurors. Amounts, dates, policy terms, recipients and network identifiers come from the final receipts and configured deployment, never from a script placeholder.

The opening is already informative at frame zero: founder in a natural setting beside a readable, moving crop of the actual claim timeline if captured. The first visual change occurs by two seconds. If footage is not yet verified, show founder only with “A family waiting for clarity”; do not stage a working result. Keep generated Kerala artwork out of the official proof sequence, or clearly label it “Illustrative artwork”.
