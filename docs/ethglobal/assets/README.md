# GuardLink submission assets

| File | Use |
| --- | --- |
| `guardlink-mumbai-cover.jpg` | Main project cover and current verified testnet results |
| `guardlink-integrations.jpg` | Sponsor integration visual for the README or pitch |
| `membership-01-apply.jpg` through `membership-04-policy.jpg` | Live GuardLink browser captures of the fresh test wallet |

The Arc, Arkiv and Uniswap Foundation marks are the sponsor icons published on the [ETHGlobal Mumbai prize page](https://ethglobal.com/events/mumbai/prizes). They identify the corresponding integrations and remain the respective owners' marks. The GuardLink cover uses verified demo counts, with claims limited to synthetic testnet activity. The browser captures contain a public test wallet and its synthetic profile.
