# Real use of the Arkiv integration

A cooperative member, reviewer or observer can open a public case timeline and see its recorded milestones and Arc payout receipt without seeing the medical documents. For an operator, the writer, entity key and linked receipt help distinguish a missing published record from a payment that never settled. [Live case timeline](https://guardlink.ajnasnb.com/transparency/?caseId=dfd3e4f9-9008-4e60-b420-f10ae15c5f81)

The demo uses labelled test wallets and synthetic cases. It demonstrates an application-level workflow for those users. Node engineers can inspect the integration feedback and case-scoped query, while infrastructure metrics are outside the app’s scope.
